# 电商月度运营数据分析

> 一个完整的分析闭环：**取数清洗 → 指标建模 → 分层归因 → 可视化 → 结论建议**。
> 回答老板最爱问的一句话——**"9 月各渠道运营做得怎么样？钱该往哪投？"**
>
> ⚠️ 数据为**模拟数据**（个人实战项目），指标口径与分析方法按真实业务标准执行。

## 业务问题

一家网店 9 月的经营复盘。整体数字看着还行，但要回答：赚了多少、靠谁赚、真赚钱吗、人留没留住、有没有被平均数骗。

## 数据

`data/` 下 5 张表（模拟）：

| 表 | 说明 | 关键列 |
|---|---|---|
| orders | 订单 600 行 | order_id, user_id, order_date, amount, category, channel, refunded |

| activity | 活跃打卡 3957 行 | user_id, act_date |

## 工具与交付

同一份分析，用三种工具各走一遍，展示全链路能力：

- **Excel**：透视表 + `XLOOKUP`/`SUMIFS` 多表核对，输出月度运营报表。
- **Python (pandas)**：`analysis.py` —— 可复现脚本，一键跑出下面所有结论。
- **SQL**：`sql/ecommerce_queries.sql` —— 用取数 SQL 复现同一套指标（JOIN / 聚合 / 窗口函数 / 日期）。
- **Tableau**：5 面板交互看板 + 渠道联动下钻 + Story 叙事（见 `tableau/`）。

## 关键发现

**① 总览**：GMV **56,364.27** ｜ 订单 **600** ｜ 去重买家 **341** ｜ 客单价 **93.94** ｜ 退款率 **8.0%**。

**② 渠道结构**：付费投放单数最少（169）却贡献最大 GMV（**38.8%**）——高客单价渠道。

**③ 营收 ≠ 利润**（按毛利率重排）：

| 品类 | 营收 | 毛利 | 毛利率 |
|---|---:|---:|---:|
| 美妆 | 12,883.96 | **7,730.38** | 60% |
| 数码 | 10,839.44 | **3,035.04** | 28% |

> 数码营收过万、毛利垫底；美妆才是利润王。**建议把资源往高毛利品类倾斜，而不是看营收排序。**

**④ 留存**：D1 **41.2%** / D7 **29.4%** / D30 **6.0%** —— 拉新有效，但一个月基本流失完。

**⑤ 辛普森悖论（核心亮点）**：
整体客单价从 **96.9 → 90.98** 看着全线下滑，但拆到渠道 **4 个里 3 个在涨**：

| 渠道 | 上半月 | 下半月 | |
|---|---:|---:|---|
| 付费投放 | 121.52 | 149.47 | ↑ |
| 直播带货 | 108.52 | 114.76 | ↑ |
| 社交裂变 | 72.60 | 77.16 | ↑ |
| 自然流量 | 70.36 | 66.33 | ↓ |

真因：高客单价的**付费投放单量占比从 40.7% 腰斩到 15.7%**——是**结构缩量，不是业务变差**。
> 所以考核建议从"整体下滑"改成"分渠道排查付费投放为何下半月大幅缩量"。

## 结论与建议

1. 品类优先级按**毛利率**而非营收排——美妆/家居优先，数码控量提价。
2. 留存 D30 仅 6%，拉新之外要补**留存/复购**动作。
3. 整体客单价下滑是**结构问题**：重点排查付费投放下半月缩量原因（预算？投放效率？），考核需分渠道分层看。
